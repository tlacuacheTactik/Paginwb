// FLUJO DE PROCESAMIENTO

Cómo funciona

Entrenamos una arquitectura YOLOv8s fusionando múltiples conjuntos de imágenes urbanas para identificar riesgos reales y calcular su posición relativa frente al usuario en tiempo real.

01 // CAPTURA ÓPTICA

Visión frontal continua

La cámara ESP32-CAM montada en el puente de los lentes observa el camino frente al usuario con lente gran angular.

02 // INFERENCIA Y UBICACIÓN

Detección con YOLOv8s

El modelo clasifica 5 tipos de obstáculos en milisegundos, prioriza el más cercano por área y determina si está a la izquierda, centro o derecha.

03 // ALERTA SONORA

Codificación por pitidos

Un mini buzzer emite 1 pitido para poste o árbol, 2 para poste caído, 3 para banqueta rota o bache y 4 para rama.
